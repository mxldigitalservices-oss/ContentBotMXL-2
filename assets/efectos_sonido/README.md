# assets/efectos_sonido/

Efectos de sonido cortos (.mp3, .wav u .ogg) que el motor sincroniza
automaticamente con cada corte entre escenas (tipo "whoosh"/transicion).
Tambien es opcional: si esta carpeta esta vacia, las transiciones de video
(disolvencia cruzada) se aplican igual, solo sin el sonido extra.

Recomendaciones:
- Clips MUY cortos (0.2-0.8s), volumen ya balanceado en el archivo original
  (el script los mezcla a `SFX_VOLUME = 0.35`, pensado para un sfx que ya
  viene razonablemente fuerte).
- Mismas fuentes de licencia libre sugeridas en `assets/musica/README.md`
  (YouTube Audio Library, Pixabay, etc.) sirven para "sound effects".
